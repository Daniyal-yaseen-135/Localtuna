# Offline Music Player

A lightweight **offline music player** built with **C++** and **Qt QML**, leveraging **data structures** for efficient song management. Play, search, and organize your local music library in a simple and intuitive interface.

---

## Features

- 🎵 Play, pause, skip, and go back to songs  
- 🔍 Search songs by title, artist, or genre  
- 📂 Browse your local music library  
- ⚡ Efficient management using data structures (linklist, graphs, etc.)  
- 🎨 Sleek and minimal **QML-based UI**
- 🎵 get recommendation from local songs

---

## Tech Stack

- **Frontend:** QML (Qt Quick)  
- **Backend:** C++ (Qt)  
- **Data Structures:** graph, linked lists, hashmaps, queue
- **Development Environment:** Qt Creator / GitHub Desktop
